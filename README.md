# قُرعة — نسخة العرض

https://activitiesclass.github.io/quraa/

نسخة من مشروع قُرعة المدرسي، بقوائم وهمية للعرض فقط: ١٢٠ اسمًا في ٦ شعب و١٢ اسمًا للهيئة التعليمية. لا تحتوي على قوائم المدرسة الأصلية.

تعمل القرعة دون تكرار، مع التناوب بين القوائم، وسجل الجلسات والتصدير والنسخ الاحتياطي والمظهر والصوت. تُحفظ البيانات في المتصفح.

مصممة البرنامج الأصلي: الأستاذة فاطمة النهدية.

التحقق: `npm test`
